Coming soon

GapWallet

GapWallet, the watch-only web wallet made for GapKeep's Signer, will be hosted here. It holds no private key: it builds transactions, shows them as QR codes for GapKeep to explain and sign, then reads the signed transaction back with the webcam and broadcasts it.

When it is here, its page will say which servers it connects to, and why: a blockchain server (Esplora) for your addresses and balance, and, only if you turn it on, a price server.
