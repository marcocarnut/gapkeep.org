GapKeepUm sistema operacional mínimo, bare-metal, para aplicativos air-gapped.

Documentação · Baixar · IDE no navegador · Código no GitHub · Segurança · Como contribuir

Sem rastreadores, sem analytics, sem cookies, sem requisições a terceiros: este site não carrega nada de nenhum outro lugar, no espírito do GapKeep. (A GapWallet tem o seu próprio site, gapwallet.org, com armazenamento separado; lá ela diz a quais servidores se conecta, e por quê.)

O GapKeep é software livre, sob a GNU GPL versão 3 ou posterior. Este site: textos e imagens sob CC BY-SA 4.0, scripts sob GPL-3.0-or-later. Documentação espelhada do commit do GapKeep 19eaea1872c1.
