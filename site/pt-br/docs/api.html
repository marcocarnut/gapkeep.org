GapKeep JavaScript API reference

<!-- Generated by tools/gen_api.py from docs/api/gapkeep-api.yaml - edit that, not this. -->

Apps are ES modules running on QuickJS. They reach the system through the modules below, imported by name:

Module Available to Purpose
gk:ui every app Widgets, layout, input, alerts
gk:sys every app App info, versions, uptime, memory, exit
gk:crypto every app Hashes, HMAC, PBKDF2, secp256k1 (ECDSA, Schnorr, BIP-32 and Taproot tweaks), hardware random bytes
gk:clock every app (setting it: "rtc") The wall clock, alarms on its marks
gk:session every app Values kept across the app's runs, in RAM, until power-off
gk:i18n every app (changing the settings: "settings") Translations, numbers, amounts and dates in the person's language
gk:data every app (only the folders its manifest lists in "data") Read-only files from the card's data folders, shared by name
gk:apps apps with the "apps" permission List and launch apps (the launcher)

Plus the globals console, setTimeout, setInterval, clearTimeout and clearInterval, and the standard JavaScript library (ES2023).

An app's own modules are imported with relative paths ("./lib/x.js"). Paths are resolved inside the app's directory; .. cannot leave it.

#gk:ui

import * as ui from "gk:ui";

#Exports

Name Type Description
Widget class Base class of all widgets. Not constructible; use for instanceof.
Container, Panel, Label, Button, TextArea, Checkbox, Switch, Dropdown, Slider, Bar, Table, QRCode, Image, Scanner, TabView classes Widgets

#Creating widgets

new ui.Label(props?)            // child of ui.screen
new ui.Label(parent, props?)    // child of another widget

props is an object of properties and event handlers. Unknown property names and invalid values throw a TypeError naming the problem, both here and in set(), so typos don't fail silently.

Widgets can be subclassed:

class Title extends ui.Label {
  constructor(parent, text) {
    super(parent, { text, font: 28 });
  }
}

Every property in the tables below is also a JavaScript property: label.text = "hi" is the same as label.set({ text: "hi" }). Properties marked readable return their current value; the others are write-only.

#Events

Event Handler property Fired when
"click" onClick Clicked, or Enter/Space while focused.
"change" onChange The value changed (by the person or by code).
"submit" onSubmit Enter in a one-line TextArea.
"focus" onFocus Received keyboard focus.
"blur" onBlur Lost keyboard focus.
"longpress" onLongPress Pressed and held.
"key" onKey A key reached the focused widget (after ui.onKey).
"press" onPress The mouse button went down on the widget, or Enter/Space while it is focused.
"drag" onDrag The mouse moved while pressed on the widget (only when it actually moved).
"release" onRelease The press ended.

Handlers receive one event object and are called with this set to the widget:

Field Description
type Event name.
target The widget.
value For value-carrying widgets: TextArea text, Checkbox/Switch checked, Slider/Bar value, Dropdown selected, TabView active.
key "key" events only: key name (see key names).
pointer "press", "drag", "release": true if from the mouse, false if from the keyboard.
x, y Same events, mouse only: position relative to the widget's top-left corner, px.
time Same events: uptime in milliseconds, microsecond resolution (as sys.uptime()).

A widget with a "drag" handler does not scroll its parents when dragged on, so drawing or entropy-collecting areas work inside scrollable pages. Holding Enter or Space does not repeat "click" or "press": auto-repeat moves and types, but never activates.

#Widgets

#Container

An invisible box for layout: no background, border or padding, sized to its content by default. Children's focus rings may draw outside it.

A Container doesn't scroll unless you set scrollable: true. A scrollable Container clips its content (rows scrolled out of view must not draw over the rest of the screen) and, unless you set padding, gets 5 px of padding so the focus rings of the widgets at its edges stay whole. If you set your own padding on a scrollable Container, leave at least 5 px for the ring: it is 3 px wide, 2 px away from the widget.

#Panel

A box with the theme's "card" look: background, border, rounded corners, padding, scrollbars when content overflows.

#Label

Text: one line or wrapped; with markup: true, in several styles.

Property Value Notes
text string Readable. May contain \n and ui.symbols. With markup, it is markup (below), and reads back as it was set.
overflow "wrap", "clip", "dots", "scroll", "scroll-circular" What happens when text is wider than the label (set a width for this to matter). With markup: "wrap", "clip" (the first line) or "dots" (set a maxHeight too).
markup boolean Readable. Set when the Label is created (new ui.Label({ markup: true, text }); changing it later throws). Then text is Pango-style markup: <b> and <i> (bold, italic, and both: at every size, drawn from outlines when first used), <tt> (the monospaced font, at the size or the next smaller), <big> and <small> (a step in ui.fonts), <u>, <s>, <span> with color ("#RRGGBB" or "#RGB"), size (one of ui.fonts), font_family="monospace", weight="bold", style="italic", underline="single", strikethrough="true"; entities &lt; &gt; &amp; &quot; &apos; &#N; &#xN;. Anything else throws a TypeError that says what and at which character: an unknown tag, bold or italic monospaced text (there is no such font), bgcolor, tags left open or crossed, a bad value, a & that starts no entity. Escape data with ui.escapeMarkup, or build the text with gk:i18n's tm(). Markup.

#QRCode

A QR code, drawn from text or bytes.

Property Value Notes
data string or Uint8Array Encoded content. Text uses the most compact single mode (numeric for digits only, alphanumeric for 0-9 A-Z $%*+-./: and space, otherwise byte mode with UTF-8); a Uint8Array is encoded as raw bytes. Throws RangeError if it doesn't fit.
ecc "L", "M", "Q", "H" Error correction level (default "M"). Never raised automatically, so the symbol is exactly what was asked for.
version number The smallest version to use, 1 to 40 (default 1): a larger one is used only if the data needs it. For a series of codes shown in turn, such as BBQr's, which should all be one version. modules gives the version used: (modules - 17) / 4.
size number Side length in px (default 160), including a 4-module quiet zone. Modules are drawn at an integer scale.
dark, light color Module colors (default black on white).
modules number Read-only. Modules per side of the current symbol (21 for version 1, +4 per version), 0 when empty.

A rejected value (data too long, size too small) throws and leaves the code unchanged. For example, a 24-word SeedQR (96 digits at ecc: "L") is 29×29, a Compact SeedQR (32 bytes at "L") is 25×25.

#Image

A picture from pixels the app supplies (GapKeep decodes no image formats).

Property Value Notes
src { width, height, data } data: a Uint8Array or ArrayBuffer of width * height * 4 bytes, RGBA with straight alpha, rows top to bottom (as canvas ImageData). Up to 1024 px a side. Copied: the app may reuse its buffer. sys.app.image and the image of apps.list() entries are in this form.

The image shows at its own size. Give the widget a width and height to scale it to fit (keeping its aspect ratio); radius rounds its corners.

new ui.Image({ src: sys.app.image, radius: 12 });

#Scanner

The camera's view, and what the kernel recognises in it: the detectors in detect. The app gets what was found (a QR code's contents), never the picture: the kernel draws the view and runs the detectors. Needs "permissions": ["camera"] in the manifest (otherwise the constructor throws). See CAMERA.md.

Property / method Value Notes
detect list of detector names Readable. Required. What to look for: "qr" (QR codes); "qr-color" (experimental: a colour QR code's colour layer, only with experimental = yes in the card's gapkeep.txt, otherwise an unknown name). An unknown name throws, listing those this system has. More detectors (e.g. ArUco markers) will come under new names, each with its own "detect" event fields. May be changed while scanning.
field "center", "full" Readable. What part of the camera's view the scanner sees. "center" (the default): the middle, at full detail: about a 26° view on the Pi camera, best for a code at 30-60 cm or a phone at arm's length. "full": all of the camera's view, with less detail per degree, so codes must be larger in the picture. Changing it restarts a running scanner.
scanning boolean Read-only. Whether the camera is on for this scanner.
start() Turns the camera on again after stop() or an error. Scanning starts by itself when the widget is created.
stop() Turns the camera off. Deleting the widget, or the app ending, does too.
onDetect handler Event "detect". Something was found; kind says what. "qr": bytes (a Uint8Array) is the code's content, the bytes of its segments as encoded, without character set conversion: ECI designators are dropped (not applied), and Kanji-mode segments arrive as Shift JIS bytes; text the same as a string if it is valid UTF-8, else null; fired again only when the content changes, or when the same code comes back after 2 s out of sight, so each part of an animated code arrives once. "qr-color" (experimental): the same code's colour layer, in an event of its own: bytes and text as for "qr", status "ok" with the colours' data in colour, or, after a second of trying, "plain" (no colour layer) or "unreadable", with colour null; a later "ok" for the same code may still follow. With both detectors, a code gives a "qr" event and a "qr-color" one.
onError handler Event "error". The camera could not start or stopped working; reason says why ("no camera", "the camera is in use by another scanner", ...). Scanning has stopped; start() tries again.

The view is 320×240 unless you set width and height; the picture (640×480 for "center") is scaled to fit, and a green outline marks what was just found. One scanner at a time can have the camera.

new ui.Scanner({
  detect: ["qr"],
  onDetect: ({ kind, bytes, text }) => console.log(`${kind}: ${bytes.length} bytes`),
  onError: ({ reason }) => (status.text = reason),
});

#ui.alert

const index = await ui.alert(message, { title, buttons });

Shows a modal dialog over the app. buttons is an array of labels (default ["OK"]). Resolves with the index of the button pressed, or -1 if the person pressed Escape. While an alert is open, Tab moves only between its buttons and ui.onKey handlers are not called. Alerts can be nested.

#ui.onKey

ui.onKey((ev) => { ... return true; });   // or ui.onKey(null) to remove

Called for every key press before it reaches the focused widget. Return true to consume the key. The event has:

Field Description
key Key name (see below).
shift, ctrl, alt Modifier state (booleans).
repeat true if the key is being held down and this press is an auto-repeat (after 400 ms, every 80 ms).

With Ctrl or Alt held, keys are delivered to the handler only, not typed.

#Key names

Printable characters are themselves ("a", "A", "7", " ", "ç"), as the keyboard layout types them (keyboard in gapkeep.txt: us or br-abnt2); an accent typed with a dead key arrives once, composed with the letter ("á"). Others: "Enter", "Escape", "Backspace", "Delete", "Tab" (check shift for Shift+Tab), "ArrowUp", "ArrowDown", "ArrowLeft", "ArrowRight", "Home", "End", "PageUp", "PageDown", "Insert", "F1"..."F9".

The Windows/Super key is reserved: it always returns to the launcher. Shift+PageUp and Shift+PageDown are the system's too: they scroll the focused widget's nearest scrollable ancestor by a page, as the mouse wheel scrolls what is under the pointer, and never reach ui.onKey.

#ui.theme

ui.theme({ dark: true, primary: "#009688", secondary: "#ffc107" });

Changes the theme for widgets created afterwards; call it before building the screen. The secondary color is also the focus ring. The system theme is restored when the app exits.

#Symbols

Icon glyphs from the built-in font, usable inside any text: audio, video, list, ok, close, power, settings, home, download, drive, refresh, mute, volume-mid, volume-max, image, tint, prev, play, pause, stop, next, eject, left, right, plus, minus, eye-open, eye-close, warning, shuffle, up, down, loop, directory, upload, call, cut, copy, save, bars, envelope, charge, paste, bell, keyboard, gps, file, wifi, battery-full, battery-3, battery-2, battery-1, battery-empty, usb, bluetooth, trash, edit, backspace, sd-card, new-line.

Names with dashes need bracket syntax: ui.symbols["eye-open"]. The same names are valid for icon in manifest.json.

#gk:crypto

import * as crypto from "gk:crypto";
Name Description
sha1(data) SHA-1, a Uint8Array(20). Broken for collisions: for HMAC-SHA1 (TOTP) and protocols that require it, not to identify data.
sha256(data) SHA-256 of a typed array (its bytes), an ArrayBuffer, or a string (as UTF-8). Returns a Uint8Array(32). Synchronous.
sha512(data) SHA-512, a Uint8Array(64).
hmac(hash, key, data) HMAC (RFC 2104) of data under key, with the hash named as in WebCrypto: a Uint8Array of the hash's size. Keys of any length (longer than a block are hashed first, as the RFC says).
ripemd160(data) RIPEMD-160, a Uint8Array(20).
hash160(data) RIPEMD-160 of SHA-256 (Bitcoin's HASH160: P2PKH and P2WPKH addresses, BIP-32 key identifiers; a fingerprint is its first 4 bytes), a Uint8Array(20).
pbkdf2(hash, password, salt, iterations, length) PBKDF2 (RFC 8018) with HMAC over hash: a Uint8Array(length). iterations 1 to 10,000,000, length 1 to 1024. A BIP-39 seed is pbkdf2("SHA-512", mnemonic, "mnemonic" + passphrase, 2048, 64) (both NFKD-normalised first: .normalize("NFKD")), about 0.1 s on a Pi Zero. Blocks until done, but, like JavaScript, is stopped by the watchdog (10 s) and the Windows key: millions of iterations take minutes.
isPrivateKey(key) Whether key is 32 bytes from 1 to n-1 (n: the curve's order).
isPublicKey(key) Whether key is a point on the curve, SEC 1 encoded (33 or 65 bytes).
publicKey(privateKey, compressed = true) The public key, 33 bytes (compressed) or 65.
publicKeyConvert(publicKey, compressed = true) The same key, compressed or not. A RangeError if it isn't on the curve.
privateKeyTweakAdd(privateKey, tweak) (privateKey + tweak) mod n: BIP-32's private child keys. A RangeError if tweak ≥ n or the result is 0 (BIP-32: skip to the next index).
publicKeyTweakAdd(publicKey, tweak, compressed = true) publicKey + tweak·G: BIP-32's public child keys (from an xpub). A RangeError as above.
ecdsaSign(hash, privateKey) ECDSA signature of a 32-byte hash, DER-encoded (at most 71 bytes; add the sighash byte yourself). Deterministic (RFC 6979), low S, and low R as Bitcoin Core's (retried with extra nonce data until R is below 2²⁵⁵).
ecdsaVerify(signature, hash, publicKey) Checks a strict-DER signature (without the sighash byte). High-S signatures fail, as in Bitcoin's standard rules.
xOnlyPublicKey(privateKey) The BIP-340 public key: the point's X, 32 bytes.
schnorrSign(message, privateKey, aux) BIP-340 signature (64 bytes) of a 32-byte message. aux: 32 bytes of auxiliary randomness; by default fresh random bytes, as BIP-340 recommends (pass zeros for a reproducible signature).
schnorrVerify(signature, message, publicKey) Checks a BIP-340 signature against an x-only public key; the message may have any length.
taprootTweakPublicKey(publicKey, tweak) Taproot's output key Q = P + tweak·G for the x-only internal key P (BIP-341): key is Q's X, parity its Y's (a script path's control block needs it). The tweak is the app's: the TapTweak tagged hash of P (and the script tree's root, if any).
taprootTweakPrivateKey(privateKey, tweak) The private key for that Q (BIP-341's taproot_tweak_seckey: negated if its point's Y is odd, then plus the tweak), to sign a key-path spend with schnorrSign.
randomBytes(n) Uint8Array(n) of random bytes, n ≤ 65536.
getRandomValues(array) Fills a typed array in place and returns it, like WebCrypto's. ≤ 65536 bytes.
rngStatus() { healthy, failure, rawBytes }.

data, key, password and salt are typed arrays (their bytes: a subarray hashes just its part), ArrayBuffers, or strings, taken as UTF-8. Hashes, HMAC and PBKDF2 run in the kernel (src/crypto, written from FIPS 180-4, the RIPEMD-160 paper, RFC 2104 and RFC 8018, checked against their test vectors): microseconds per block on a Pi Zero, where the same in JavaScript takes about a millisecond. The copies made of keys and data are overwritten after use.

secp256k1 (Bitcoin's curve) is Bitcoin Core's libsecp256k1 (MIT), whose arithmetic on secrets is constant-time. Its keys, hashes, tweaks and signatures are typed arrays or ArrayBuffers, never strings: 32 bytes for private keys, hashes, messages to sign and tweaks; public keys SEC 1 encoded (33 bytes compressed, 65 not) or, for BIP-340 and Taproot, x-only (32). Wrong types throw a TypeError, wrong sizes and keys that aren't keys a RangeError; the verify and is functions return false instead. BIP-32, addresses and transactions are the app's, in JavaScript on these: e.g. a child key is privateKeyTweakAdd(k, I.slice(0, 32)) with I = hmac("SHA-512", chainCode, data). On a Pi Zero, an ECDSA signature takes about 9 ms, a BIP-32 derivation step under 2 ms, a BIP-39 seed 93 ms.

Each group (RIPEMD-160, PBKDF2, secp256k1) checks itself against known answers before its first use; if that fails, it throws an InternalError until reboot.

Where the randomness comes from. The BCM2835's hardware random number generator, treated as a noise source of unknown quality. Every raw byte passes NIST SP 800-90B's continuous health tests (Repetition Count and Adaptive Proportion, tuned for an assumed 1 bit of entropy per byte), 4096 bytes are tested at boot, and each 32 output bytes are SHA-256 of 256 raw bytes. If a test ever fails, the generator shuts off until reboot: randomBytes and getRandomValues then throw an InternalError, and never return weak bytes.

The hardware RNG is undocumented. Apps handling secrets should treat it as a supplement to entropy the person provides (dice, coins), not a replacement. (In the simulator, the bytes come from the host's random source.)

To run code written for WebCrypto unchanged, give it a small adapter:

import * as gkcrypto from "gk:crypto";
globalThis.crypto = {
  getRandomValues: gkcrypto.getRandomValues,
  subtle: { digest: async (alg, data) => ({ "SHA-1": gkcrypto.sha1, "SHA-256": gkcrypto.sha256,
                                             "SHA-512": gkcrypto.sha512 })[alg](data).buffer },
};

#gk:clock

import * as clock from "gk:clock";

The wall clock, kept by the system whatever app runs. A Pi Zero has no battery-backed clock, so the time is lost at power-off: until the clock app sets it, it counts from 1970-01-01 at boot (status().set is false). Date.now() and new Date() follow this clock, and local time (getHours(), ...) is UTC plus the clock's fixed offset (no daylight saving rules). Every app may read it; setting it needs "permissions": ["rtc"] (the others throw a TypeError). See CLOCK.md.

Name Description
now() Milliseconds since 1970-01-01 UTC: the same as Date.now().
status() { set, time, trimPpm, utcOffset, drift }: whether the time was set since boot; the time (ms, as now()); the trim correcting the crystal, in parts per million (+ runs faster); local time's offset from UTC in minutes (-180 for UTC-03:00); and drift, null or what the last set() measured: { correction, over, trimPpm, uncertaintyPpm }: the clock was correction seconds off (+: fast) after over seconds, so trimPpm would have kept it right, give or take uncertaintyPpm (half a second's error in each setting). Measured only when the sets are at least an hour apart.
set(time) Needs "rtc". Sets the time (ms since 1970, or a Date; from 2000 to 2099) and returns status(), with the drift measured since the last set().
setTrim(ppm) Needs "rtc". The trim, -500 to 500 ppm. Takes effect from now, without changing the time. At boot it comes from clock_trim_ppm in the card's gapkeep.txt.
setUtcOffset(minutes) Needs "rtc". Local time's offset, -720 to 840 minutes (UTC-12:00 to UTC+14:00). At boot it comes from utc_offset in gapkeep.txt.
every(seconds, fn) Calls fn on the clock's marks: whenever the UTC time is a multiple of seconds (whole, 1 to 86400), e.g. at :00 and :30 for 30, and at once (changed: true) whenever the clock is set or its trim or offset change. fn gets { time, changed }. Returns an id for cancel. Ends with the app.
cancel(id) Stops an every.

#gk:session

import * as session from "gk:session";

Values an app keeps across its runs: leave it, use other apps, come back, and they are still there. Only until the device is switched off: the store is in the kernel's RAM, and nothing is ever written to the card. Each app has its own, which no other app can read, and neither can another version of the app: the store is filed under the app's id and its hash. Up to 64 KiB per app (keys and values), 1 MiB for all.

const accounts = session.get("accounts") ?? [];
// ... the person adds one ...
session.set("accounts", accounts);

Values are copied in and out, as a structured clone: objects, arrays, strings, numbers, booleans, null, BigInts, Dates, ArrayBuffers and typed arrays. Changing a value after set doesn't change what is stored: set it again. Not stored (a TypeError, and the store is left as it was): functions, Map, Set, getters, cycles. Objects come back as plain objects (not their class). A typed array is stored with its whole buffer: store a.slice() rather than a view into a larger buffer.

What is removed, replaced or cleared is overwritten in memory before it is freed. Secrets kept here are still in RAM until power-off: give the person a way to forget them (clear()).

Name Description
set(key, value) Stores a copy of value under key (1 to 64 bytes of UTF-8), replacing what was there; undefined removes the key. A RangeError if the app's values would take over 64 KiB (or the store is full), and nothing changes.
get(key) A fresh copy of the value, or undefined.
remove(key) Removes the key; false if it wasn't there.
keys() The app's keys, in the order they were first set.
clear() Removes all of the app's values.
usage() Bytes the app's keys and values take, and its limit (65536).

#gk:i18n

import { t, plural } from "gk:i18n";

new ui.Label({ text: t("Sign this transaction?") });
ui.alert(t("Signed {n} of {total} inputs.", { n, total }));
label.text = plural(count, "{n} code", "{n} codes");

The app's text in the person's language. The English text is the key, written where it is used; the translations are the app's catalogs, lang/<language>.json, loaded and checked when the app starts (see Languages). A key without a translation shows in English. Numbers, amounts and dates are written the same way on every build (QuickJS has no Intl).

The language, the number marks and the keyboard layout come from gapkeep.txt at boot (language = pt-BR, decimal_mark, group_mark) and can be changed until power-off by an app with "permissions": ["settings"] (the Settings app); without it the setters throw a TypeError. A new language applies to the apps started after the change, and at once to the app that made it, through onLanguageChange.

Name Description
t(text, params?) The translation of text, or text itself. {name} is replaced by params.name: numbers as formatNumber writes them, other values as strings; a BigInt throws a TypeError (format amounts first). A {name} not in params stays as written; {{ and }} are braces. $context tells apart the same English in two meanings: t("Open", { $context: "verb" }) is the catalog key "verb\u0004Open". Keys should be string literals, so tools/i18n.py finds them.
tm(text, params?) As t, for a Label with markup: true: every param is escaped (ui.escapeMarkup), so a name, an address or a scanned text never becomes a tag. If text has a tag or an entity it is markup (its translation keeps the same tags: checked on load), else plain text, escaped too.
plural(n, one, other, params?) t(one) or t(other) by the language's plural rule (English and Portuguese: one for 1, other otherwise, 0 too), with n added to params.
language() The language, a BCP 47 tag: "en", "pt-BR", or "qps" (a pseudo-language for testing: every translated text accented, about 40% longer and in brackets).
languages() The languages the system has (English and those the launcher has a catalog for), each named in itself: [{ tag: "en", name: "English" }, { tag: "pt-BR", name: "Português (Brasil)" }].
setLanguage(tag) Needs "settings". Changes the language until power-off. This app's catalog is loaded again at once and its onLanguageChange handlers run; other apps get it when they start. A RangeError for a language not in languages() (or "qps").
onLanguageChange(fn) Calls fn after the language or the marks change, to redraw. Returns a function that removes it.
marks() The marks numbers are written with: { decimal: ".", group: "," } in English, { decimal: ",", group: "." } in Portuguese, unless set otherwise. group may be "" (no grouping). For apps that draw numbers themselves.
setMarks(marks) Needs "settings". The marks, until power-off; null or a mark left out: the language's own. If only one is given and the language's other mark is the same, the other is the other one ({ decimal: "," } in English: 1.234,5). A RangeError if both are given and the same.
keyboard() The keyboard layout: "us" or "br-abnt2" (keyboard in gapkeep.txt).
keyboards() The layouts there are: ["us", "br-abnt2"].
setKeyboard(layout) Needs "settings". The layout, from keyboards(), at once for every app, until power-off. A dead key pending is dropped. RangeError for a layout not in keyboards().
formatNumber(x, { decimals }?) Thousands grouped, the language's decimal mark: 1,234,567.5 or 1.234.567,5. decimals (0 to 20): exactly that many, rounded; otherwise as many as the number has. Never an exponent.
formatSats(sats) Whole satoshis, grouped: 2,100,000. A safe integer or a BigInt, else a TypeError.
formatBtc(sats, { decimals = 8 }?) Satoshis as BTC, never through floating point: 1.23456789, 20.999.999,97690000. decimals (0 to 8) is the least shown: trailing zeros beyond it are left out, other digits never are (formatBtc(120000000, { decimals: 0 }) is 1.2). No unit: write "{amount} BTC" in the text, so a translation can move it.
parseNumber(text) A number as typed, with a sign if any. What could be read two ways is refused ("1.000" in Portuguese, "1,000" in English: one or a thousand?); a lone mark that can't be a thousands separator (0.001, 1,5) is the decimal mark in any language; several marks must be the language's thousands, properly grouped. Refusals are a RangeError whose message, translated, says what to type.
parseBtc(text) An amount in BTC as typed, in whole satoshis (a Number: 21 million BTC fit exactly), with the rules of parseNumber; no sign, at most 8 decimals, at most 21,000,000 BTC.
formatDateTime(seconds, { utc }?) ISO 8601 with a space, in every language: 2026-11-08 14:03:05, in the clock's local time (gk:clock's UTC offset); with { utc: true }, in UTC and followed by UTC. seconds since 1970; fractions are dropped.
formatDate(seconds, { utc }?) 2026-11-08, as formatDateTime.
formatTime(seconds, { utc }?) 14:03:05, as formatDateTime.

#gk:data

import * as data from "gk:data";

Read-only files the person put on the SD card when preparing it, in data/<folder>/... beside apps/: public keys, address books, word lists. An app reads only the folders its manifest lists, "data": ["pgp"], and nothing can write them. Apps that list the same folder share it. Any kind of file: binary (an exported OpenPGP key) or text (.asc). APPS.md, "Data files" says how to lay them out and put them on a card, or build them into a sealed kernel.

for (const { name, size } of data.list("pgp")) {
  const key = data.read("pgp", name);          // Uint8Array
  // ... parse it, show its fingerprint ...
}

The data is not part of the app's hash. The app hash names the code, and is the same on every card; the data is whatever the card holds, and whoever can change the card can change it. So show the person what matters before using it: for a key, its fingerprint, to be compared with one they trust; hash(folder) names the whole folder, as the launcher shows it.

Every folder some installed app lists is read at boot, all of it, hashed, and kept in memory until power-off; these functions never touch the card, which can be taken out once the launcher is up. What the app reads is what was hashed. Limits: 4 MB per file, 8 MB and 256 files per folder, 32 folders and 32 MB in all. A folder over them, or with a name that is not printable ASCII, is refused at boot: every call on it throws, saying why. Names starting with . (macOS's ._x) are skipped. A sealed build reads no card; its data folders, if any, are built into the kernel and served the same way.

Every refusal is a TypeError that says what is wrong: a folder that is not in the manifest, a path that leaves the folder (.., ., a leading /, a \), a file that isn't there. A folder that isn't there (not on the card; every folder without a card, or in a sealed build without built-in data) has no files: list() returns [] and hash() null.

Name Description
list(folder) The folder's files, { name, size }, sorted by name (byte order): name is the path inside the folder, with / between folders ("keys/alice.asc"), size in bytes. [] if there is no such folder.
read(folder, name) The file's bytes, a fresh copy. name as list() gives it.
readText(folder, name) The file as UTF-8 text. A TypeError if it isn't valid UTF-8 (or holds a NUL byte); read() gives its bytes.
hash(folder) The SHA-256 of the folder's files, 64 hex digits, as the launcher shows it: the app hash's scheme, so tools/bundle_apps.py --data-hash <folder> computes it on a computer. null if there is no such folder.

#gk:apps

Requires "permissions": ["apps"] in the manifest; importing it otherwise throws a ReferenceError. Used by the launcher.

Name Description
list() Array of { id, name, version, description, icon, image, permissions, source, hash, experimental, suite, data } (as sys.app) (name and description in the language: each app's own catalog translates them) for every app not marked hidden, and not marked experimental unless the card's gapkeep.txt says experimental = yes: the built-in apps (sorted by id; test builds list their test-only apps last), then those from the SD card (sorted by folder; a suite's apps, in apps/<suite>/<id>, where the suite's folder sorts, each with suite set to the suite's id).
suites() The suites on the card (apps/<id>/suite.json), sorted by id: { id, name, description, icon, image }, as for apps (name and description in the language, from the suite's own lang/ catalogs). A suite whose apps were all refused is listed too; the launcher shows only suites with apps.
dataHash(folder) The hash of the data folder data/<folder>, as gk:data's hash() gives it: the launcher shows those an app lists (only those are read, at boot). null if there is no such folder, or no app lists it; a TypeError if it was refused (too big, a bad name).
launch(id) Stop the current app and start id (after the current handler returns). Throws if there is no such app, or if it is experimental and experimental features are off.
card() The SD card: { status, problems }. status is "ok" (/apps was read), "none" (no card), "unreadable" (no FAT file system), "no-apps" (no /apps folder) or "disabled" (sealed build). problems lists the folders in /apps that were not loaded: [{ folder, error }], at most 16.
