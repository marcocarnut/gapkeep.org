Glossary: Brazilian Portuguese (pt-BR)

The terms GapKeep's apps use in Brazilian Portuguese, as does GapWallet, a companion web wallet (not yet published), so the same thing has the same name everywhere. Translators follow them, and propose changes here, not in a catalog alone.

tools/i18n.py check --lang pt-BR reads the table below and warns about a translation with a word from the "Avoid" column: a warning for the reviewer, not a failure, since some of those words are right in other senses ("a maior parte"). Whole words, ignoring case; a hyphenated word is one word, so "frase-senha" is not "senha".

#Style

  • Address the user as "você". Buttons and menu items are infinitives ("Adicionar esta conta", "Copiar"); instructions are imperatives ("Escolha uma rede", "Digite um valor").
  • "Transação" and "PSBT" are feminine ("a PSBT está assinada"); "QR code" is masculine and stays in English.
  • Never translated: GapKeep, GapWallet, dice39, codex32, BIP numbers, script and key formats (P2WPKH, zpub, xpub, Base43, BBQr), units (BTC, sat, sat/vB), network names (mainnet, testnet, signet).
  • Numbers, amounts and dates come from gk:i18n (formatBtc, formatDate...), never typed into a translation.

GapKeepUm sistema operacional mínimo, bare-metal, para aplicativos air-gapped.

Documentação · Baixar · IDE no navegador · Código no GitHub · Segurança · Como contribuir

Sem rastreadores, sem analytics, sem cookies, sem requisições a terceiros: este site não carrega nada de nenhum outro lugar, no espírito do GapKeep. (A GapWallet tem o seu próprio site, gapwallet.org, com armazenamento separado; lá ela diz a quais servidores se conecta, e por quê.)

O GapKeep é software livre, sob a GNU GPL versão 3 ou posterior. Este site: textos e imagens sob CC BY-SA 4.0, scripts sob GPL-3.0-or-later. Documentação espelhada do commit do GapKeep a0274664025e.
