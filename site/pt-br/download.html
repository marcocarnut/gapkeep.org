Imagens para cartão SD

Duas imagens para o Raspberry Pi Zero v1.3, prontas pra ir num cartão microSD. A única diferença é o idioma em que o GapKeep inicia (a de português do Brasil também já vem com o teclado no layout ABNT2); dá pra trocar no aplicativo Configurações, até desligar, ou no arquivo gapkeep.txt do cartão.

Saiu o GapKeep 0.1.0.A primeira versão pública, de 2026‑11‑10. Notas da versão e todos os arquivos: versão v0.1.0 no GitHub. Você também pode montar um cartão a partir do código (em inglês), ou experimentar o GapKeep no navegador antes.

Todas as versões, com seus hashes, no GitHub → · SHA256SUMS · RELEASE.txt

  1. O que vem numa versão

    Cada versão no GitHub traz, para cada idioma (en ou pt-BR):

    • gapkeep-<versão>-<idioma>.img.zip: a imagem, pra gravar no cartão com uma das ferramentas abaixo.
    • gapkeep-<versão>-<idioma>.zip: os arquivos do cartão, pro jeito mais simples ainda: copiar tudo para um cartão FAT32.

    E, para a versão inteira, o SHA256SUMS (o hash de cada arquivo) e o RELEASE.txt (o commit do GapKeep, e os hashes do kernel e dos aplicativos que o lançador mostra).

  2. Confira o download

    Antes de gravar qualquer coisa, confira se o arquivo é o publicado: calcule o SHA-256 dele e compare com o SHA256SUMS da versão no GitHub. Têm de ser idênticos, caractere por caractere.

    Windows

    certutil -hashfile gapkeep-1.0-pt-BR.img.zip SHA256

    ou, no PowerShell:

    Get-FileHash .\gapkeep-1.0-pt-BR.img.zip

    macOS

    shasum -a 256 gapkeep-1.0-pt-BR.img.zip

    Linux

    sha256sum -c --ignore-missing SHA256SUMS

    na pasta com o download e o SHA256SUMS: a resposta deve ser OK (ou SUCESSO, com o sistema em português).

    (1.0 representa a versão que você baixou.)

  3. Grave no cartão

    Escolha um dos jeitos. Gravar uma imagem apaga tudo o que estiver no cartão.

    O mais fácil, no Windows, no macOS e no Linux: Raspberry Pi Imager

    A ferramenta oficial e gratuita da Raspberry Pi: raspberrypi.com/software.

    1. Em Choose OS (escolher o sistema), vá em Use custom e escolha o .img.zip que você baixou (não precisa descompactar).
    2. Em Choose storage (armazenamento), escolha o seu cartão microSD.
    3. Grave. Se ele oferecer personalizar o sistema (Wi-Fi, nome de usuário e afins), pule: essas opções não valem para o GapKeep.

    Também nos três: balenaEtcher

    Gratuito, em etcher.balena.io.

    1. Flash from file, e escolha o .img.zip.
    2. Select target: o seu cartão microSD.
    3. Flash! Ele confere o cartão depois de gravar.

    No Linux, sem instalar nada

    • GNOME Disks ("Discos" na maioria das distribuições): descompacte a imagem, selecione o cartão à esquerda e, no menu, Restaurar imagem de disco…, escolhendo o .img.
    • Linux Mint: o Gravador de imagem USB (mintstick) grava um .img descompactado no cartão.
    • Para quem já tem prática: dd. Descompacte, descubra o nome do dispositivo do cartão e grave: 
      unzip gapkeep-1.0-pt-BR.img.zip
lsblk                      # ache o cartão: /dev/sdX ou /dev/mmcblk0
sudo dd if=gapkeep-1.0-pt-BR.img of=/dev/sdX bs=4M conv=fsync status=progress

      Confira o nome do dispositivo duas vezes.O dd sobrescreve o que você mandar, sem perguntar: se apontar para o disco do computador em vez do cartão, lá se vai o disco. Compare o tamanho que o lsblk mostra com o do seu cartão, e desmonte as partições do cartão antes.

    No macOS

    Raspberry Pi Imager ou balenaEtcher, como acima.

    Mais simples ainda: copie os arquivos

    O cartão do GapKeep é só um punhado de arquivos num cartão FAT32, então dá pra dispensar a imagem:

    1. Formate o cartão em FAT32. Cartões acima de 32 GB vêm formatados em exFAT, e também precisam ir para FAT32. O Raspberry Pi Imager faz isso (Choose OS → Erase, que formata em FAT32), ou o utilitário de disco do seu sistema.
    2. Descompacte o gapkeep-<versão>-<idioma>.zip e copie tudo o que tem dentro para a raiz do cartão.
    3. Ejete o cartão direitinho antes de tirar.

  4. A primeira vez

    Coloque o cartão no Zero, ligue a tela (mini-HDMI) e o teclado (na porta marcada USB, pelo adaptador OTG) e, por último, a alimentação (na porta marcada PWR). Primeiro aparece a tela colorida do próprio Pi; uns 12 segundos depois de ligar, quase tudo isso do firmware do Pi, o lançador está na tela. A partir daí, o cartão pode ser retirado e guardado em outro lugar.

  5. Confira o que roda

    Um download conferido prova que o arquivo é o publicado. O GapKeep também deixa você conferir o que ele está executando, na própria tela, comparando com o RELEASE.txt:

    • O kernel: aperte i no lançador para ver as informações do sistema, com o SHA-256 do kernel.img (o mesmo que sha256sum kernel.img).
    • Cada aplicativo: o SHA-256 dele aparece no rodapé do lançador quando o seu bloco está selecionado. Ele cobre todos os arquivos do aplicativo, ou seja, cada linha de código que ele executa.
    • Compilações reproduzíveis: com o compilador fixado, o mesmo commit gera o mesmo kernel.img, byte a byte, onde quer que seja compilado; qualquer pessoa pode recompilar uma versão e comparar (tools/check_reproducible.sh; veja Building, em inglês). As próprias imagens da versão também são reproduzíveis: tools/check_reproducible.sh --release.

    Esses são os hashes de um kernel legítimo: um kernel adulterado pode mostrar o hash que quiser. Para conferir um cartão em que você não confia, calcule os hashes dos arquivos dele num computador confiável.

    Se algum hash for diferente do publicado, não use esse cartão, e por favor avise a gente.
